# TopDownShooter

A 2D top-down zombie shooter made in Unity.

This is my first game made in Unity. The goal is to survive as many zombie waves as possible while using different weapons and power-ups.

## Features
- Player movement and shooting
- Different types of zombies
- Zombie AI that follows the player
- Zombie waves that get harder over time
- Different weapons
- Power-ups and perk machines
- Health and damage system
- Game over screen
- Visual effects

## Built With
- Unity (Universal 2D)
- C#
- Visual Studio

## Project Status
The game is still in development.
